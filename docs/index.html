ORBIT 0.8.2 · HOW TO PLAY

Three synth tracks and a drum machine, running the actual FM-1 firmware in WebAssembly. HOME opens Event Tape: an editor for sequencer notes and drum events, not an audio tape recorder.

FIRST STEPS

  • ALGORITHM selects track 1–4. Start with track 4 and choose a drum kit with PRESETS; the white keys play its drums.
  • On synth tracks, turning PRESETS on Tape or Mixer loads sounds immediately and opens a short audition list. Sound-design pages do not silently load sounds.
  • SELECT sets tempo on Tape and in layers, or changes pages elsewhere. MASTER sets output volume.

RECORDING A FIRST LOOP

  • Stopped: REC arms. In free mode, play and press REC on the next downbeat to close the loop; ORBIT sets its tempo and starts playback. PLAY abandons a free take.
  • tempo records 1, 2 or 4 bars at the selected tempo. With START count, PLAY begins a one-bar count-in.
  • Playing: REC starts overdub; press it again to end overdub. PLAY starts/stops playback. Hold REC to clear the selected track; release before confirmation completes to cancel.

PAGES AND HELD LAYERS

EDIT / ENV / FX / LFO open sound pages. Tap the same button again or turn SELECT to move within its page family. KNOB1–4 edit the displayed blue / green / white / orange values.

Hold a layer button for 0.35 s to show its page; using a layer control shows it immediately. Hold the layer and tap HOME to lock it; another page/layer button unlocks it. Hold HOME for settings.

The physical SEL button is between FX and ENV; it is not the SELECT encoder. SEL + a key sets the root; SEL + KNOB1 selects chords and KNOB2 selects a scale.

EVENT TAPE

HOME returns to Tape (the full-screen visualizer was removed in 0.8.2). KNOB1 sets the destination head, KNOB2/3 set the inclusive region, and KNOB4 chooses COPY or LIFT.

SEL + OCT− captures the region; LIFT also removes it. SEL + OCT+ drops at the head, overwriting destination events. ALGORITHM selects source/destination track; synth clips stay on synth tracks and drum clips stay on drums.

Plain OCT−/OCT+ change synth octave, not Tape events. EDIT + OCT−/OCT+ undo/redo supported sequence edits.

DRUM GRID AND KIT

On track 4, tap SEQ or EDIT from Tape/Mixer for DRUMS; tap again to switch GRID / KIT, or turn SELECT left/right. In GRID, black keys select voices and white keys toggle that voice's steps. OCT−/OCT+ change 16-step pages.

KIT is the live-pad view. For live drums, hold ARP and a drum key for a roll; hold OCT−/OCT+ with a hit for ghost/hard levels.

STEPS AND LOCKS

Hold SEQ and tap white keys to set/clear steps. SEQ + the first four black keys selects a step page. With a step held, KNOB1–4 edit note/lane, velocity/level, ratchet and nudge.

Touch a sound parameter, then use SEQ + step + PRESETS to set its lock; ALGORITHM changes the destination. SEQ + step + OCT+ cycles fill conditions. Each track has 24 parameter locks.

SOUNDS AND MACROS

The default bank has 17 engines and 189 factory sounds, including SWARM, PULSE, FM4 and oscillator-granular CLOUD. Tracks 1–3 share eight synth voices globally; engine limits also apply.

On a synth track, EDIT then SELECT reaches MACROS: KNOB1–4 assign destinations. SELECT back to PERFORM edits their values. HOME remains Tape.

To save a sound and its assignments, stop playback, open SAVE > USER, choose slot 1–32 with KNOB1, then turn KNOB4 SAVE positively twice within the confirmation window. KNOB2 LOAD recalls a USER sound with the same two-turn confirmation.

ENVELOPE, LFO AND EFFECTS

ENV edits ATK / DEC / SUS / REL; ENV DEST sets FLT / PIT / SHP depths and SYNC. LFO edits RATE / WAVE / PHS / FADE; LFO 2 sets SYNC / TRIG / POL; LFO DEST sets PIT / FLT / SHP / AMP depths.

Zero LFO depths mean no audible modulation. Try LFO DEST AMP near half, then adjust RATE. FX includes sends, FILTER with FILT / RES / TYPE, SLICER and INSERT. DLY 2 sets the delay TYPE: MONO, WIDE (the right echo 13 ms later) or PING (echoes alternate left and right). Hold FX for punch-in effects.

MIXER AND SECTIONS

On Tape, GLO opens Mixer. KNOB1–4 set track levels; SELECT moves through LEVEL, PAN and selected-track controls. Press GLO again for global pages. Hold GLO: white keys 1–4 mute, 5–8 solo, 9 holds fill, 10 schedules next-bar fill and 16 taps tempo.

Stopped: SAVE + white keys 5–8 stores sections A–D; repeat to confirm an overwrite. SAVE + keys 1–4 recalls them, at the next bar while playing. Tap several while holding SAVE for a chain. SAVE on Tape opens SONG.

PROJECTS AND EXISTING AUTOSAVE

Open an editing page, tap SAVE, then turn SELECT for USER / PROJECT / TOOLS. PROJECT has four slots: KNOB1 selects, KNOB2 erases, KNOB3 loads and KNOB4 saves. Actions require confirmation and flash writes require stopped playback.

There is no built-in demo-song loader or DEMO SONG menu. Earlier patterns may return from your existing autosave; the update does not clear them. To start empty, first save anything you want to keep, stop, open SAVE > TOOLS and confirm KNOB4 NEW (NEW PROJECT). Leave playback stopped for autosave; saved sections are separate.

Controls follow the ORBIT user guide and source overview. Emulator fork: sabliran/sloop-web-emu.

IN THIS EMULATOR

  • Hold means click-and-hold or touch-and-hold a button — or hold its computer key (1–0 for the function buttons; full map in the line below).
  • Knobs turn by dragging vertically or scrolling; on a rotated phone, drag along the device's own up — toward its knobs.
  • ORBIT projects, settings and user presets use the existing local browser flash and survive reloads. Autosave follows the firmware's stopped-inactivity timing; browser data clearing can remove it.
  • Not available here: the USB web editor, sample upload, USB audio, Bluetooth and firmware install. Do not enter hardware calibration, which waits on the real key matrix. Browser use does not verify hardware boot or timing.
